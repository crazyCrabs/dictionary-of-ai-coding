# CONTEXT

This repo's domain glossary. Terms here are load-bearing: when output names a
domain concept, use these terms as defined. Don't drift to synonyms.

## Glossary

- **Canonical 术语** — 词条的英文术语形态:文件名、`internal/Curriculum.md` bullet、交叉链接目标全部保留英文原词。是链接稳定性和 diff 可读性的锚点。中文正文不得改动 Canonical 术语。
- **混排正文** — 词条正文的形态:散文用中文书写,Canonical 术语在首次出现处给中译对照(如"压实(Compaction)"),后续出现直接用英文术语。英文原文不保留在工作区(git 历史是唯一归档)。
- **翻译规范** — 约束 agent 产出中文词条的规则集(对应英文侧的 CLAUDE.md 文风规则)。位于 `internal/translation.md`。
